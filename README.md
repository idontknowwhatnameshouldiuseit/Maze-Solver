# Maze-Solver
C++ Maze Solver using DFS, backtracking, and custom data structures.

- Reads a 2D maze from hard-coded test cases
- Implements DFS pathfinding with a backtracking mechanism
- Uses Object-Oriented Programming (OOP) design principles
- Custom template Linked List and Stack data structures
- Language: C++
- IDE: Visual Studio
- Concepts: OOP, DFS, Backtracking, Template Classes, Data Structures

 Project Structure
- `main.cpp` - Entry point and test cases
- `MazeSolver.cpp` / `MazeSolver.h` - Core solver logic
- `LinkedList.h` - Template Linked List implementation
- `Stack.h` - Stack implemented using Linked List
